# Green Wood Grammar School - Frontend Showcase

A modern, highly responsive frontend web application built as a personal showcase project. This project was developed to demonstrate advanced UI/UX engineering, complex React state management, and premium web design principles.

## 🌟 Key Features

- **Cinematic Media Hub (Bento Grid):** A custom, asymmetrical media gallery using a Bento-style layout with advanced CSS hover states and gradient overlays.
- **Custom React Portal Lightbox:** A from-scratch, full-screen media viewer that breaks out of the DOM hierarchy using React Portals to prevent stacking context bugs. Features background scroll-locking, responsive typography, and embedded video support.
- **Responsive Architecture:** Fluid typography and layout adjustments ensure a flawless experience across mobile, tablet, and ultra-wide desktop screens.
- **Custom SVG Integration:** Hand-coded, premium glassmorphism social icons bypassing traditional heavyweight icon libraries.
- **Scroll-Triggered Animations:** Smooth, cascading fade-in and slide-up animations built with standard CSS and Intersection Observers.

## 🛠️ Tech Stack

- **Framework:** React 18 (via Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React & Custom SVGs
- **Deployment Ready:** Optimized for fast builds and excellent Lighthouse performance scores.

## 🚀 Running the Project Locally

To view this showcase project on your local machine:

1. **Clone the repository** (or download the source files).
2. **Install dependencies:**
   ```bash
   npm install
   ```

### Running the Development Server

To start the Vite development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

Open your browser and navigate to the `localhost` URL provided in the terminal (usually `http://localhost:5173/`) to view the application.
